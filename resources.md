# Helpful resources for Modern Software Dev Course


# 1. Atlassian
Atlassian is a company that creates software tools used by many teams to help manage projects according to Agile methodologies.
[atlassian.com/software-development](https://www.atlassian.com/software-development)


# 2. Github Docs
Github has resources and tutorials on how to navigate through Github and use Git effectively.
[docs.github.com](https://docs.github.com/en/get-started)


# 3. TED Talks on Youtube
Many software engineering experts share their industry experiences and insights on TED Talks. Here's one I recommend.
[Learning Software Engineering During the Era of AI](https://www.youtube.com/watch?v=w4rG5GY9IlA&t=515s)
